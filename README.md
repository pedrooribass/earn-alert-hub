# Opportunity Finder

BEER MONEY APP

Quero que cries uma aplicação mobile-first extremamente polida, com foco em retenção, simplicidade e utilidade.

NÃO quero uma app centrada em níveis, XP ou gamificação.

A gamificação pode existir em segundo plano.

A proposta principal é:

“Nunca mais perder uma oportunidade.”

O utilizador instala a aplicação porque quer ser avisado rapidamente quando surge uma oportunidade relevante.

O utilizador mantém a aplicação porque confia que somos a fonte mais rápida e organizada para descobrir oportunidades.
